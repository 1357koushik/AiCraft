# Contributing to AiCraft

## Git Commit Message Conventions
When making commits in this repository:
- **Do not use conventional commit prefixes**: Never start commit messages with prefixes such as `feat:`, `feat(...)`, `refactor:`, `refactor(...)`, `fix:`, `fix(...)`, `chore:`, etc.
- **Use human-tone English titles**: All commit messages must be titled with clear, natural, human-tone English summarizing the changes (e.g. `Document natural English commit message policy`, `Add falling sand and gravel suffocation mitigation`, `Implement water bucket clutching reflex`).
